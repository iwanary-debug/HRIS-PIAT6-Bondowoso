# HRIS PIAT6 — UI Specification

## Visual direction
Modern institutional dashboard, clean white/light surfaces, deep blue/navy sidebar,
blue accent, subtle cards, readable typography, generous spacing, responsive.

## Main shell
- Left sidebar desktop
- Mobile drawer
- Top search
- Breadcrumb
- Notification area
- User/profile menu
- Main content area

## Dashboard
KPI cards:
- Total Karyawan
- Aktif
- Nonaktif/Resign
- PKWT
- PKWTT
- Kontrak perlu perhatian
- Cuti/Izin pending
- Kehadiran

Charts/tables:
- Karyawan per Bidang
- Karyawan per Jabatan
- Status Akad
- Pendidikan
- Kontrak akan berakhir
- Pengajuan pending
- Recent activity

## Employee detail
Tabs:
Profil | Kepegawaian | Pendidikan | Kehadiran | Cuti/Izin |
Payroll | BPJS/Benefit | Kompetensi | Pelatihan | Kinerja |
Dokumen | Disiplin | Mutasi/Promosi | Resign/Terminasi | Audit

## UX
- Search/filter/pagination
- Clear empty/loading/error states
- Confirmation for destructive actions
- Avoid crowded screens
- Prefer selection/clicking over typing
- Desktop and mobile usable
